# 面试前信息调查（Intake Survey）

> 填写后用于全方位搜集信息并定制面试官 / 公司画像。可直接在下方补充答案，或另存为 JSON 供 `persona` 命令读取。

- **applicant_name**：你的称呼？ 
- **goal_type**：申请类型？ （选项：['保研', '申博', '科研岗求职', '答辩', '组会汇报', '海外phd']）
- **org_name**：目标学校 / 公司 / 实验室名称？ 
- **position_or_program**：申请的具体岗位 / 项目 / 导师？ 
- **interviewer_name**：已知面试官姓名？（可空，能具体到人则画像更准） 
- **interviewer_style**：你了解面试官的风格？ （选项：['严厉压力型', '温和引导型', '技术深挖型', '不确定']）
- **known_focus**：面试官 / 岗位特别看重的方面？（可空） 
- **timeline**：面试时间线 / 轮次？ 
- **materials_available**：你已有哪些材料？（多选） （选项：['简历', '论文/专利', '项目代码', '成绩单', '推荐信', '其他']）
- **extra_notes**：其他想让面试官关注或回避的点？
